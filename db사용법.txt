# 🚬 흡연구역 데이터베이스 구축 및 공공데이터 연동 가이드

## 1. 공공데이터포털(data.go.kr) 데이터 다운로드 방법
1. [공공데이터포털(https://www.data.go.kr)](https://www.data.go.kr) 접속
2. 검색창에 **"흡연구역"** 또는 **"지정흡연구역"** 검색
3. 주요 제공 데이터:
   - **전국흡연구역표준데이터** (행정안전부/지자체)
   - 서울특별시 각 자치구(강남구, 서초구, 마포구, 영등포구 등) 흡연구역 위치 정보 (CSV/JSON/API)
4. CSV 파일 다운로드 또는 OpenAPI 인증키 발급

---

## 2. 앱 내 로컬 데이터 교체 방법 (JSON 방식)
- 경로: `assets/data/smoking_areas.json`
- 공공데이터 CSV 파일을 아래 JSON 형식으로 변환하여 저장하면 앱 재실행 시 즉시 반영됩니다.

```json
[
  {
    "id": "고유식별자 (예: SMK-001)",
    "name": "흡연구역 명칭 (예: 강남역 11번 출구 뒤)",
    "address": "도로명 또는 지번 주소",
    "latitude": 37.498095,
    "longitude": 127.027610,
    "radius": 10.0,
    "type": "개방형 / 완전폐쇄형 부스 / 라인형",
    "description": "상세 위치 설명"
  }
]
```

---

## 3. OpenAPI 실시간 연동 시 확장 방법
- `lib/services/smoking_area_service.dart` 파일의 `loadSmokingAreas()` 메서드에서 `http.get()`을 사용하여 공공데이터포털 REST API를 직접 호출하도록 구현할 수 있습니다.
- 예:
```dart
final response = await http.get(
  Uri.parse('https://api.odcloud.kr/api/.../v1/uddi:...?serviceKey=YOUR_API_KEY&page=1&perPage=100'),
);
```

## 4. 지원 지도 SDK 안내
- 본 프로젝트는 **완전 무료 & 상업적 이용 가능(OpenStreetMap / CARTO)** 한 `flutter_map` 라이브러리를 사용합니다.
